Tôi đã cấu hình sẵn tệp môi trường be/.env và settings.py dùng SQLite (be/db.sqlite3) và InMemoryChannelLayer để bạn chạy được ngay mà không bắt buộc phải bật MySQL hay Redis.

Cách 1: Chạy nhanh bằng 1 cú nhấp chuột

Chạy trực tiếp file run.bat ở thư mục gốc của dự án (nhấp đúp vào run.bat hoặc gõ .\run.bat trong Terminal).

Cách 2: Chạy bằng lệnh trong Terminal (PowerShell / CMD)

Mở Terminal tại thư mục gốc của dự án và chạy:

powershell
# 1. Chạy server (môi trường ảo .venv đã được cài đặt sẵn)
.\.venv\Scripts\python.exe be\manage.py runserver 127.0.0.1:8000

Nếu sau này bạn muốn tạo lại dữ liệu mẫu (hoặc nạp lại thuốc/vaccine):

powershell
# Nạp lại toàn bộ dữ liệu mẫu (Tài khoản, Ca trực, Thuốc/Vaccine, Lịch hẹn, Bệnh án)
.\.venv\Scripts\python.exe be\manage.py seed_sample_data
# Hoặc chỉ nạp lại dữ liệu Thuốc & Vaccine
.\.venv\Scripts\python.exe be\manage.py seed_thuoc_vaccine

.venv\Scripts\python -X utf8 be\manage.py test test_feature1_web test_feature2_app test_feature3_performance test_feature4_api test_feature5_unit -v 2

2. Các lệnh chạy thực tế từng công cụ (đã kiểm chứng 100%)

Chạy toàn bộ 73 Test Cases bằng Pytest (pytest-django):

powershell
.venv\Scripts\pytest

(Kết quả: collected 73 items 
→
→ 62 passed, 11 failed trong 11.98s)

Chạy toàn bộ 73 Test Cases bằng Django TestCase (unittest):

powershell
.venv\Scripts\python -X utf8 be\manage.py test test_feature1_web test_feature2_app test_feature3_performance test_feature4_api test_feature5_unit -v 2

Chạy kiểm thử tự động trình duyệt Web SPA bằng Selenium WebDriver:

powershell
.venv\Scripts\python -X utf8 be\selenium_web_runner.py --headless

(Bỏ --headless nếu muốn mở cửa sổ Chrome/Edge thật để trình chiếu thao tác điền form)

Chạy kiểm thử chịu tải nhiều người truy cập bằng Locust hoặc JMeter:

Locust Web UI (mở giao diện biểu đồ tải tại http://localhost:8089

powershell

powershell
