CÔNG CỤ 3: LOCUST — Kiểm thử Hiệu năng & Chịu tải nhiều người truy cập (Feature 3)
(File kịch bản tải: be/locustfile.py)
================================================================================

* Bước chuẩn bị bắt buộc: Mở Terminal 1 để bật Server Django trước:
  .venv\Scripts\python be\manage.py runserver 127.0.0.1:8000

[Cách 3.1 - CHẠY TỰ ĐỘNG 100% TRÊN TERMINAL (Headless Mode - không cần mở trình duyệt)]:
- Mở Terminal 2 và chạy lệnh:
  .venv\Scripts\locust -f be/locustfile.py --headless -u 25 -r 5 -t 30s --host=http://127.0.0.1:8000 --html=locust_report.html
- Làm gì tiếp theo?: KHÔNG CẦN LÀM GÌ THÊM. Locust tự động sinh 25 người dùng ảo đồng thời (Lễ tân, Bệnh nhân, Kế toán), bắn tải liên tục trong 30 giây, tự động in bảng thống kê độ trễ (ms) & RPS ra Terminal, đồng thời xuất ra file báo cáo "locust_report.html".

[Cách 3.2 - MỞ GIAO DIỆN BIỂU ĐỒ WEB UI CỦA LOCUST]:
- Bước 1: Mở Terminal 2 và chạy lệnh:
  .venv\Scripts\locust -f be/locustfile.py --host=http://127.0.0.1:8000
- Bước 2 (Làm gì tiếp theo?):
  1. Mở trình duyệt Chrome/Edge truy cập địa chỉ: http://localhost:8089
  2. Trên màn hình Locust Web UI, nhập vào 3 ô:
     - Number of users (Số người truy cập cùng lúc): nhập 25
     - Spawn rate (Tốc độ thêm user mỗi giây): nhập 5
     - Host: giữ nguyên http://127.0.0.1:8000
  3. Bấm nút "Start" (Start swarming).
  4. Bấm qua tab "Statistics" để xem bảng tốc độ phản hồi từng API (TC_PERF_01..04, TC_PERF_09), hoặc bấm tab "Charts" để xem biểu đồ đường thời gian thực.
